#Power BI Sales, Profit & Discount Analysis

This section extends the Excel-based analysis by using Power BI to build an interactive dashboard for sales performance, profitability, and discount impact analysis.

#Key Features:
- Data cleaning and transformation using Power Query
- DAX measures for total sales, total profit, profit margin, and average discount
- Interactive dashboard with KPI cards, trend analysis, and discount vs profit insights
- Slicers for Year, Category, Region, and Customer Segment

#Tools Used:
- Power BI Desktop
- Power Query
- DAX
